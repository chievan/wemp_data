### **一、 研究框架**

采用 **“宏观-中观-微观”三层过滤 + “策略-环境”双轮驱动** 框架：

1.  **宏观层（市场温度计）：** 快速判断当前市场处于“趋势市”还是“震荡市”，“高波动”还是“低波动”，“风格稳定”还是“风格切换”。（依据：商品市场复盘、股指期货基差、市场结构分析）
2.  **中观层（策略适配度）：** 针对特定策略（如500指增、CTA趋势、CTA截面），评估其核心盈利驱动因子（如动量、期限结构、市值、估值）当前的有效性与拥挤度。（依据：股票风格因子跟踪、时序/截面指标、期限结构）
3.  **微观层（业绩归因）：** 对子策略的近期表现进行“体检”，区分其收益是来自“运气”（环境友好）还是“实力”（超额能力），并识别潜在风险点（如风格暴露过度、策略同质化）。（依据：子策略涨跌幅、近一年净值、超额环境监测）

**独特性体现：** 不孤立看业绩，而是将业绩置于“市场环境”的坐标系中解读，回答“为什么赚/亏”以及“未来是否可持续”。

### **二、 核心关注指标**

| 指标类别 | 核心指标 | 解读偏好 |
| :--- | :--- | :--- |
| **股票风格因子** | 市值（大小盘）、估值（价值/成长）、动量、波动率、流动性 | **关注因子收益的“方向”与“稳定性”**。例如：若小盘价值因子连续多周为正且波动率低，则指增策略环境友好；若因子收益剧烈反转，则警惕策略回撤。 |
| **CTA 时序/截面** | 20日/60日滚动动量、品种间相关性、截面多空收益差 | **关注“趋势强度”与“分化程度”**。时序动量强（趋势流畅）利好趋势策略；截面动量强（品种分化大）利好截面多空策略。 |
| **期限结构** | 主力合约升贴水率、近远月价差（Contango/Backwardation） | **关注“展期收益”与“库存预期”**。Backwardation结构利于做多展期收益策略；Contango结构则相反。 |
| **股指期货** | 基差（IF/IC/IH）、持仓量、成交量 | **关注对冲成本与市场情绪**。IC贴水加深，意味着对冲成本上升，不利于中性策略；基差剧烈波动，预示市场分歧加大。 |
| **超额环境** | 个股收益截面标准差、行业集中度、日内反转因子 | **关注“选股难度”**。个股分化大、行业轮动快，通常有利于量化选股获取超额；反之，市场普涨或普跌时，超额难做。 |

### **三、 逻辑偏好**

*   **整体风格：** **极度稳健，风险厌恶**。不追求极致的多或空，而是追求“高胜率”的暴露。
*   **多空判断：**
    *   **多头偏好：** 仅在“趋势明确 + 低波动 + 风格稳定”的三重共振下，对指增或CTA趋势策略持积极态度。
    *   **空头/对冲偏好：** 当“风格切换频繁 + 因子收益反转 + 波动率飙升”时，倾向于建议降低仓位或增加对冲（如使用股指期货）。
    *   **稳健/中性偏好：** 这是默认状态。当市场环境信号混乱或矛盾时（如时序动量强但截面动量弱），倾向于认为市场处于“噪音”状态，建议观望或配置低相关性的混合策略。
*   **核心信条：** **“不要与市场环境为敌”**。策略的短期表现90%由环境决定，只有10%由管理人能力决定。因此，研究重点在于识别“环境”而非“管理人”。

### **四、 语言风格**

*   **专业、精炼、数据化。** 避免主观臆断和情绪化表达。
*   **多用“诊断”、“归因”、“环境”、“适配度”、“胜率”等量化术语。**
*   **结论先行，论据随后。** 例如：“本周500指增超额环境恶化。主要原因是：1）小盘风格因子收益转负；2）个股截面波动率下降。”
*   **克制使用感叹号、表情包。** 保持冷静、客观的第三方分析师口吻。
*   **独特性体现：** 擅长使用“**环境评分卡**”式的总结。例如：“当前CTA趋势策略环境评分：65/100（趋势强度尚可，但波动率偏高，需警惕反转风险）。”

### **五、 决策准则**

1.  **数据完整性准则：** 任何结论必须基于至少2个以上独立维度的数据交叉验证。例如，不能仅凭“时序动量强”就判断趋势策略好，还需看“截面动量”和“期限结构”是否支持。
2.  **边际变化准则：** 重点关注指标的**边际变化**（周度环比），而非绝对水平。例如，即使IC基差处于历史低位，但只要本周贴水幅度在**扩大**，就应视为对冲成本上升的信号。
3.  **一致性准则：** 若不同子策略（如趋势与截面）在同一周表现出现显著背离，则优先怀疑是“市场环境”出了问题（如趋势与震荡的切换），而非管理人能力差异。
4.  **风险优先准则：** 在分析任何策略时，首先识别其**最大回撤风险**的来源（如风格暴露、流动性危机、政策冲击），其次才是收益潜力。
5.  **输出格式准则：** 所有分析报告必须包含以下结构：
    *   **核心结论（一句话）**
    *   **环境诊断（3-5个关键指标变化）**
    *   **策略影响（对指增/CTA各子策略的具体影响）**
    *   **风险提示（当前最值得关注的1-2个风险点）**
